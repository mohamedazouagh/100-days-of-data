# 100 Days of Data

A structured, day-by-day path from plain Python to pandas, SQL and basic machine learning.
Each day has a short explanation, runnable code and an exercise with a checked solution.

| Phase | Days | Focus |
|---|---|---|
| 1 | 1–20 | Python for data |
| 2 | 21–45 | pandas |
| 3 | 46–65 | SQL (SQLite) |
| 4 | 66–85 | Visualisation & statistics |
| 5 | 86–100 | Intro machine learning |
